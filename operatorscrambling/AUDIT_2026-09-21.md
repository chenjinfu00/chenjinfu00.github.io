## 结论

有限格点 OTOC 的算符顺序正确，小系统独立对照通过。新加的无限格点 Lanczos 递推有严重符号错误，旧 b₂ 及后续系数无效；对应的渐近增长率和数值李雅普诺夫上界结论撤回。程序和两张网页已修复，原始 JSON/PNG 没有覆盖。

## 主要问题与处置

| 问题 | 影响 | 修订 |
|---|---|---|
| `L=i[H,.]` 的 Lanczos 递推错误地减去上一基向量 | 基向量不正交，b₂ 起失真 | Python 和增长页均改为加号；加入独立矩阵、闭合链与正交性测试 |
| 将有限项差分称为渐近斜率严格下界，再据此显示速率上界 | 逻辑不成立，且旧系数本身错误 | 撤回数值界，改为有限阶系数诊断；明确一维理论还涉及对数修正 |
| 能量窗口种子随请求步数变化，且被描述为无限格点守恒能量模 | 不同步数比较了不同种子；边界从第一步参与 | K 改为独立参数；标为边界敏感的有限窗口总能量 |
| 态矢量页将一个壳层代表点的曲线复制到该壳层全部格点 | 未计算点被当成实测数据；壳层平均标签错误 | 未计算项保留 NaN；图例、JSON、CSV 只列实际代表点 |
| 能量投影贡献 `P_H` 被等同于完整 `A_W(∞)` | 忽略其他守恒量与简并；“扣除后必衰减”无保证 | 改名并纠正文案、图注、公式及导出字段 |
| UI 自动降到 6 点，运行入口却重新抬到至少 20 点 | 实际算的网格和用户看到的不同，耗时增加 | 统一允许 2–600 点；实际数值同步显示；种子 0 也正确保留 |
| 导出读取当前可变输入，而曲线属于上次运行 | 模型、种子和数据无法对应 | 使用不可变运行快照；记录积分器、空间/随机采样、时间与格点 |
| 只凭一个壳层估速度，或没有前沿也输出“前沿后”统计 | 指标含义与可用数据不一致 | 速度至少需两个到达壳层；晚时窗从实测最远壳层到达后 2 时间单位开始 |
| 周期长度 2 的混合 XY 键按无向键去重 | 丢掉不同的反向 Pauli 相互作用 | 混合 Pauli 键保留方向；同 Pauli 键维持无向去重约定 |
| 态矢量保存多份全时间轨迹；稀疏生成元含大量重复条目 | 内存随时间点数快速增长，矩阵乘法冗余 | 逐时间点处理滚动态；合并相同翻转/相位的矩阵项，直接构建 CSR |
| 单次随机态结果被称为完整精确迹，且范数漂移被当作总误差 | 混淆积分误差和采样误差 | 明确一个样本无采样误差条；小范数漂移只是必要检查 |
| Python 可行性程序接受 N 却始终构造 4×4 键 | 其他 N 的模型错误 | 构图与 N 一致并校验显式形状 |
| DTWA 在长度 2 的周期轴重复邻居，第一输出时刻强制当作零 | 特定尺寸/时间网格计算错误 | 唯一邻居约定和从零推进到首个输出时刻；切向差分与 RK4 收敛测试 |

## 修正后的关键数字

默认无限方格点模型 `J=1, hx=1.05, hz=0.5`、Z 源：

| 系数 | 旧存档 | 修正值 |
|---|---:|---:|
| b₁ | 2.100000000 | 2.100000000 |
| b₂ | 5.885575588 | 4.123105626 |
| b₃ | 10.977054065 | 5.523000037 |
| b₄ | 16.847464658 | 6.777935580 |
| b₈ | 44.646478255 | 10.836412712 |

解析 b₂=√17。旧结果满足 b₂²=17+4b₁²，正是符号错误引入的多余分量；旧第二基向量与源重叠约 −0.713609，而应为零。修正后的前 8 阶 Python/JavaScript 相互吻合，Python 完整 Gram 矩阵误差约 2.8×10⁻¹⁴。

相关原始理论来源：[Parker et al., A Universal Operator Growth Hypothesis (2019)](https://arxiv.org/abs/1812.08657)。它讨论的是渐近系数增长；有限项数值不确定渐近 α，不能自行代入为严格李雅普诺夫界。即使已知 α 的下界，也不能由 λ≤2α 推出 λ 的上界。

## 性能证据

同一台机器、同一 Node 进程中的短对照；下述耗时不是浏览器或任意模型的普遍承诺：

- 3×3 短计算：273 ms → 158 ms，数值差约 4×10⁻¹⁵。
- 4×3 PBC 混合场 Ising 的态矢量生成元：393,216 → 105,988 个存储非零项；CSR 有效数据约 4.75 MB → 1.30 MB。
- 上述矩阵连续 100 次向量乘：58.3 ms → 18.0 ms；构建 95.3 ms → 36.2 ms。
- 态矢量不再保存三套完整时间轨迹；滚动态内存随代表点数与 2ᴺ 增长，输出曲线本身仍随时间点数增长。
- Pauli 生成元改为先发现可达空间、再直接填充稀疏矩阵，避免同时保存大型 JavaScript 三元组数组；新增 800 万矩阵条目的资源上限。这一优化通过了主网页回归测试，但未单独测定峰值内存。
- Taylor 步长使用保证的诱导范数界，避免将功率迭代的下方估计误当作上界；遇到未收敛、非有限值或过大演化尺度会报错。保留协作式取消，单次大矩阵乘本身不能被中断。

## 原始数据还能支持什么

- `krylov_bn_infinite.json`、`krylov_bn_plot.png`：旧 b₂ 起无效；没有把旧图替换成新图以掩盖来源。
- N=16 的两个种子时间网格分别为 6 点和 10 点，不能按数组下标平均。旧 README 的平均表无法据当前存档直接复现，本次没有插值拼接或重算全 N=16。
- N=12：只确认上述两个几何在 seed0 下的指定短时间点，不声称全时间、全种子重现。
- DTWA 原始值可到 6292.71 / 23594.63。它们超出 Pauli 量子平方对易子的 [0,4] 范围，可作为经典切向增长存档，不能作为晚时量子 OTOC。未认证旧速度比值和无限平面外推。
- 较小周期格点和较大经典格点的差异不能单独证明量子热力学极限速度，也不能认证通用的乘法修正。

## 剩余限制

1. 深阶 Lanczos 的全局正交性、完整 N=16 网格、DTWA 的量子精度与热力学极限收敛都没有在本次认证。
2. 主网页仍默认单个随机态和壳层代表点，未增加多种子误差条或所有格点态矢量计算。图例与导出现在如实标注。
3. 实际网页视觉布局、点击、字体加载、剪贴板和下载交互尚未浏览器验收：现有工具的 URL 策略拒绝读取本地 `file:` 页面。没有用本地服务器或其他浏览器表面绕过限制。结构检查通过不能替代视觉验收。
4. 主网页与增长页的默认模型不同：主网页 2D 预设 hx=3.05，增长页默认 hx=1.05。对照两页时须手动统一全部耦合、源算符及模型；它们本来计算的观测量也不同。
